# Portfolio — Youssef Id Ali

Site statique (HTML, CSS, JavaScript), sans dépendances ni build.

## Lancer
- Double-clic sur `index.html`, ou : `python3 -m http.server 8080` puis http://localhost:8080
- Déploiement : glisser le dossier sur Vercel, Netlify ou GitHub Pages.

## Modifier le contenu
- Textes, expériences, projets, certifications : `index.html` (sections commentées).
- Couleurs et typographie : variables `:root` en tête de `styles.css`.
- Photo : remplacer `assets/photo.png`. CV : remplacer `assets/CV-Youssef-Id-Ali.pdf`.
- Nouveau projet : dupliquer une carte `<article class="card project">` ; la carte « Prochaine réalisation » est un emplacement à remplacer.

## À compléter
- Photo en meilleure résolution (celle du CV fait 200×200 px).
- Résultats chiffrés par expérience ou projet (absents du CV, donc non affichés).
- Niveaux de langue, autres réseaux (GitHub…), URL réelle du site pour les balises SEO.
